# Learnova

Learnova is a modern online learning platform website designed to help students and professionals learn new skills through structured courses and learning paths.

## About the Project

Learnova provides a simple and user-friendly interface where users can explore courses, view learning paths, learn about instructors, check pricing plans, read frequently asked questions, and access a login page.

The project is currently developed using HTML and CSS, with JavaScript planned for adding interactive functionality.

## Features

- Responsive landing page
- Course listing page
- Learning paths
- Instructor showcase
- Pricing plans
- FAQ section
- About page
- Contact page
- Login page
- Responsive design for different screen sizes
- Clean and modern UI/UX
- Navigation between multiple pages

## Technologies Used

- HTML5
- CSS3
- JavaScript
